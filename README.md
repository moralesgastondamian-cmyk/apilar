# Apilar

Juego de bloques que caen, hecho en un solo archivo HTML sin dependencias. Encajá las piezas, completá filas para borrarlas y subí de nivel cada 10 líneas.

## Cómo jugar

Abrí `index.html` en el navegador.

| Tecla | Acción |
|---|---|
| ← → | Mover |
| ↓ | Bajar más rápido |
| ↑ o X | Girar |
| Z | Girar al revés |
| Espacio | Soltar de golpe |
| C | Guardar pieza |
| P | Pausa |

En celulares aparecen botones táctiles debajo del tablero.
